# 🏡 CozyNest – AI House Price Prediction Web Application

CozyNest is a full-stack Machine Learning web application that predicts house prices based on various property features using a trained Random Forest Regression model. The application combines machine learning with a modern, responsive web interface to provide users with an intuitive property price estimation experience.

The primary objective of this project was not only to build a machine learning model but also to demonstrate the practical application of advanced frontend development concepts, responsive web design, and Flask backend integration in a real-world project.

---

## 📖 Project Overview

CozyNest allows users to enter property details such as:

- Area
- Number of Bedrooms
- Number of Bathrooms
- Stories
- Parking Spaces
- Main Road Access
- Guest Room
- Basement
- Hot Water Heating
- Air Conditioning
- Preferred Area
- Furnishing Status

The application preprocesses the user input, applies the same encoding used during model training, and predicts the estimated market value of the property using a trained Random Forest Regressor.

# ⭐ Project Summary

CozyNest is a complete end-to-end Machine Learning web application developed to demonstrate the integration of regression models with a modern responsive web interface.

The project showcases practical implementation of advanced CSS layouts, Flexbox, CSS Grid, positioning techniques, responsive web design, media queries, mobile-first development, Flask backend integration, machine learning model deployment, and clean software engineering practices.

It serves as both a functional AI-powered house price predictor and a demonstration of full-stack development skills suitable for software engineering and machine learning portfolios.
