Why Choose CozyNest?

Accurate Predictions

Our machine learning model estimates house prices using real property features to provide reliable predictions.

Data-Driven

Predictions are generated from trained regression models instead of fixed rules, helping users make informed decisions.

Instant Results

Enter your house details and receive an estimated market value within seconds.

Machine Learning Models

Linear Regression

Establishes a baseline by modelling the relationship between house features and price using a linear equation.

Decision Tree

Learns decision rules from the data and captures non-linear relationships between property features and price.

Random Forest

Combines multiple decision trees to improve prediction accuracy and reduce overfitting. This is the final model used in CozyNest.
